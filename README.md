# Urban Flood Watch

Build the complete working SIH26085 Adaptive Hyperlocal Urban Flood Nowcasting & Municipal Decision Support System prototype described by the user. Use Lovable Cloud for shared persisted/demo state and server logic where needed. Create a polished responsive municipal command center and separate citizen reporting interface. Implement all named navigation pages, central interactive OpenStreetMap/Leaflet map with controllable layers and detail panels, shared demo simulation (start/pause/reset and speed) that progresses through the exact Zone A/D17 scenario and consistently updates rainfall, sensors, reports, risk, priorities, alerts, timeline, charts, recommendations, and resources. Clearly distinguish Prediction, Observation, Adaptation, Decision, and Resource Allocation throughout. Include roles, action/recommendation acceptance, data readiness, system architecture visual, demo disclaimers, seeded fictional Indian-city data, 10–15 zones, 15–25 drains, 10–20 sensors, critical infrastructure and roads. Make the end-to-end scenario compelling and functional, not disconnected mock screens.
